# Xe Launcher

Android home-screen launcher with Liquid Glass design, categorised app drawer, black-and-white glass icons and Xe Studio.

- Download: https://github.com/XenoORIGIN/xe-launcher/releases/latest/download/xe-launcher.apk
- Website: https://xenoorigin.github.io/xe-launcher/
- Android only (APK). Built automatically by GitHub Actions.
