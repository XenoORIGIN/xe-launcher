# Xe Launcher — เอกสารการออกแบบ (v2)

วันที่: 2026-11-20
เจ้าของ: Kantaphon (Xeno_F1)
สถานะ: รออนุมัติ
ต้นแบบหน้าตา: `xe-drawer-mockup.html` (App Drawer v2)

---

## 1. เป้าหมายและเหตุผล

Xe Launcher คือแอป Home Launcher สำหรับ Android ที่ Kantaphon ทำเพื่อความสนุก (โปรเจกต์ส่วนตัว) หน้าตา **คลีน มินิมอล แบบ Apple-inspired** ใช้ **Liquid Glass** เป็นเอกลักษณ์ มี **แอนิเมชันลื่นทั้งแอป** และมีเครื่องมือสร้างของเอง (วอลเปเปอร์ ไอคอน Widget) พร้อม **เว็บไซต์** สำหรับดาวน์โหลด

แรงบันดาลใจด้านฟีเจอร์คือ Smart Launcher ที่เจ้าของใช้อยู่ (App Drawer แบ่งหมวด, หน้าตั้งค่า, Widget ทรงแคปซูล) แต่หน้าตาทั้งหมดเป็นของ Xe เอง

- เครื่องเป้าหมาย: **Samsung Galaxy A16 5G** (Android 14+, One UI, 1080×2340)
- รองรับ **Android เท่านั้น** แจกเป็นไฟล์ **APK**
- เจ้าของไม่มีคอมพิวเตอร์ → build บน GitHub Actions, ดาวน์โหลด APK จากมือถือ

## 2. เป้าหมาย (Goals)

1. ตั้งเป็นหน้า Home หลักและใช้งานประจำวันได้จริง
2. Liquid Glass บนทุกแผง: Dock, แถบหมวด, ปุ่มวงกลม, โฟลเดอร์, เมนู, Widget, หน้าตั้งค่า
3. **ไอคอนค่าเริ่มต้น = ไอคอนจริงของแอปแปลงเป็นขาวดำ บนกระเบื้องกระจกดำ** (สไตล์ "กระจกดำ")
4. App Drawer แบ่งหมวด: จัดอัตโนมัติ + ย้ายแอป/เพิ่ม/ลบ/เปลี่ยนชื่อหมวดเองได้
5. **แอนิเมชันทั้งแอป** โดยเฉพาะตอนเลือกหมวด
6. **หน้าตั้งค่า** ครบ (ดูข้อ 9)
7. **Xe Studio** — เครื่องมือสร้าง: วอลเปเปอร์, ไอคอน, Widget แบบอิสระ
8. Widget ของแอปในเครื่อง + Xe Glass Widgets
9. UI ไทย/อังกฤษ ฟอนต์คลีนแบบ Apple
10. **เว็บไซต์** หน้าแนะนำ + ปุ่มดาวน์โหลด APK

## 3. สิ่งที่ไม่ทำ (Non-goals)

- ไม่ลง Play Store, ไม่ทำ iOS/เดสก์ท็อป
- ไม่รองรับ Icon Pack ภายนอก (มี Icon Creator แทน)
- ไม่มี Widget อากาศ, ไม่มี "แตะสองครั้งล็อกจอ", ไม่มี Private Space ในรอบนี้ (Samsung มี Secure Folder อยู่แล้ว)
- ไม่มีระบบบัญชีผู้ใช้/ออนไลน์

## 4. Anti-goals (ล้มเหลวแม้จะทำงานได้)

- **กระตุก** — แอนิเมชันและกระจกต้องลื่นบน A16 (ชิประดับกลาง) มีตัวเลือกลดคุณภาพกระจก/แอนิเมชัน
- **รก** — เว้นที่ว่างเยอะ ตัวอักษรน้อย
- **ก๊อป Apple ตรง ๆ** — ห้ามใช้ไอคอน ฟอนต์ SF วอลเปเปอร์ หรือโลโก้ Apple
- **อัปเดตแล้วการตั้งค่าหาย** — เซ็นด้วยคีย์เดียวกันทุกเวอร์ชัน
- **UI ล้นกรอบ** — ทุกองค์ประกอบต้องอยู่ในขอบของแผงตัวเอง (เจ้าของเจอปัญหานี้ในต้นแบบแรก)

## 5. ข้อจำกัด

- โค้ดบน GitHub บัญชี `XenoORIGIN`, build ด้วย GitHub Actions
- Android 13+ ไม่ให้แอปอ่านรูปวอลเปเปอร์ระบบ → Xe จัดการวอลเปเปอร์เอง (ข้อ 8.7)
- ติดตั้งครั้งแรกต้องอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" และตั้ง Xe เป็นแอปหน้าหลัก

## 6. แนวทางที่พิจารณา (Approaches)

| แนวทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **Kotlin + Jetpack Compose (native)** ✅ | คุมระบบ Launcher ได้เต็มที่ (Widget host, shortcuts, วอลเปเปอร์), shader กระจกได้, แอนิเมชันสปริงลื่น, build บน Actions ง่าย | โค้ดเยอะกว่า |
| Flutter | UI สวยทำง่าย | API ของ Launcher ต้องเขียน native bridge เยอะ, backdrop blur หนักบนเครื่องระดับกลาง |
| WebView / React Native | คุ้นกับ JS | ไม่เหมาะกับ Launcher, ช้า |

**เลือก: Kotlin + Jetpack Compose** (การตัดสินใจของ Claude — เจ้าของมอบเรื่องเทคนิคให้)

เว็บไซต์: **HTML/CSS/JS ล้วน บน GitHub Pages** (เจ้าของใช้ GitHub Pages อยู่แล้วกับโปรเจกต์อื่น)

## 7. การออกแบบหน้าตา

- **ฟอนต์:** Inter (อังกฤษ) + Noto Sans Thai (ไทย) ฝังในแอปและเว็บ — ใกล้ฟอนต์ Apple ที่สุดที่ใช้ได้ฟรี (OFL)
- **หัวข้อใหญ่ตัวหนา** แบบ Large Title ของ iOS, ตัวอักษรอื่นเล็กและสะอาด
- **ทรง:** squircle สำหรับไอคอน, แคปซูล (pill) สำหรับแถบและปุ่ม, วงกลมสำหรับปุ่มไอคอน
- **ค่าเริ่มต้น:** โหมดมืด + วอลเปเปอร์ดำ + ไอคอนกระจกดำขาวดำ
- โหมดสว่าง/มืด/อัตโนมัติ, สีเน้น 1 สี

### Liquid Glass (ตามรูปอ้างอิงที่เจ้าของส่ง)
1. **Backdrop blur** วอลเปเปอร์ด้านหลัง (Haze, API 31+)
2. **Refraction** บิดภาพด้านหลังแบบเลนส์/ของเหลว (AGSL RuntimeShader, API 33+)
3. **Specular rim** ขอบสะท้อนแสง สว่างบนซ้าย มีประกายสีรุ้งจาง ๆ
4. **Inner glow** แสงเรืองด้านในขอบบนและล่าง (แบบเม็ดกระจกสีดำในรูปอ้างอิง)
5. **Tint** ฟิล์มขาว/ดำโปร่งแสง + noise บาง ๆ
6. **Press squish** — กดแล้วกระจกยุบ/ยืดเล็กน้อยแบบของเหลว

ตั้งค่า "คุณภาพกระจก": สูง / ปกติ (ค่าเริ่มต้น) / ประหยัด

### ไอคอนแอป Xe Launcher เอง
squircle กระจกดำ ตัวอักษร "Xe" ขาว ขอบสะท้อนแสง (การตัดสินใจของ Claude)

## 8. ฟีเจอร์

### 8.1 หน้า Home
- หลายหน้า เลื่อนซ้าย-ขวา วอลเปเปอร์เลื่อนตามแบบ parallax
- ตาราง 4–6 คอลัมน์, Dock แคปซูลกระจก
- ปัดขึ้น → App Drawer, ปัดลง → แผงแจ้งเตือน (เปลี่ยนเป็นค้นหาได้)
- กดค้างที่ว่าง → โหมดแก้ไข (ไอคอนสั่น, ลากย้าย, ปุ่ม Widget / วอลเปเปอร์ / Xe Studio / ตั้งค่า)
- กดค้างที่ไอคอน → เมนูกระจก: shortcuts ของแอป, แก้ไอคอน, ย้ายหมวด, ซ่อน, ข้อมูลแอป, ถอนการติดตั้ง
- Badge การแจ้งเตือน (จุด/ตัวเลข/ไฮไลต์ไอคอน)

### 8.2 App Drawer (หน้าแอป) — ตามต้นแบบ v2
- หัวข้อชื่อหมวดตัวใหญ่ + ปุ่มวงกลมกระจก: ค้นหา, Play Store, เมนู
- ตาราง 4 คอลัมน์
- **แถบหมวดแคปซูลกระจกด้านล่าง** มีฟองกระจกบอกหมวดที่เลือก
- ปัดซ้าย-ขวาเปลี่ยนหมวด (ลากตามนิ้วจริง)
- **หมวดอัตโนมัติ:** ใช้หมวดที่แอปประกาศไว้ใน Android (เกม, เสียง, วิดีโอ, รูปภาพ, โซเชียล, ข่าว, แผนที่, งาน) + รายชื่อแพ็กเกจที่ Xe เตรียมไว้; แอปที่ไม่รู้หมวด → "แอปอื่น"
- **แก้เองได้:** เพิ่ม/ลบ/เปลี่ยนชื่อ/เปลี่ยนไอคอนหมวด, เรียงลำดับหมวด, ย้ายแอปข้ามหมวด, เปิด/ปิดแถบหมวด
- เมนู ⋯ → แผ่นตั้งค่าหน้าแอป: เพิ่ม shortcut / โฟลเดอร์ / หมวด, แถบหมวด, การเรียง (A–Z, ใช้บ่อย, ติดตั้งล่าสุด), แอปที่ซ่อน, ล็อกเลย์เอาต์

### 8.3 หน้าค้นหา
- ค้นแอป (ไทย/อังกฤษ), ค้น shortcuts ของแอป, ค้นเว็บ (เปิดเบราว์เซอร์), เครื่องคิดเลขในช่องค้นหา

### 8.4 โฟลเดอร์ / ซ่อนแอป
- ลากทับเพื่อสร้างโฟลเดอร์ เปิดเป็นแผงกระจกกลางจอ เปลี่ยนชื่อได้
- ซ่อนแอปจาก Home, Drawer, ค้นหา

### 8.5 ระบบไอคอน
| สไตล์ | ลักษณะ |
|---|---|
| **กระจกดำ (ค่าเริ่มต้น)** | ไอคอนจริงของแอปแปลงเป็น **ขาวดำ** วางบนกระเบื้องกระจกดำ ขอบสะท้อนแสง |
| กระจกสี | ไอคอนสี บนกระจกที่ย้อมสีหลักของไอคอน |
| กระจกใส | กระเบื้องกระจกใส ไอคอนสีเดิม |
| ต้นฉบับ | ไอคอนเดิมของแอป |
- ตัวเลือกเสริม: ทรงกรอบ (squircle/วงกลม/มุมมน), ขนาด, แสดง/ซ่อนชื่อ, ความเข้มขาวดำ
- แก้รายแอปได้ หรือใช้ไอคอนที่สร้างใน Xe Studio

### 8.6 Widget
**ก. Widget ของแอปในเครื่อง** — AppWidgetHost, ขอสิทธิ์ผูก, หน้า config, ปรับขนาดตามตาราง

**ข. Xe Glass Widgets** (แรงบันดาลใจจากหน้า Home ของเจ้าของ):
- แคปซูลกลุ่มแอป (2–4 ไอคอนในแคปซูลกระจก)
- แคปซูลปุ่มลัด (เช่น เปิดแอป, กล้อง, บันทึกเสียง)
- นาฬิกาตัวใหญ่ (หลายสไตล์: ตัวหนา, ลายเส้น, ตัวเขียน), นาฬิกาเข็ม
- แคปซูลเวลา + วันที่
- รูปภาพ (มุมโค้ง เลือกรูปเอง เช่น ตารางเรียน)
- วงแหวนแบตเตอรี่, ปฏิทินเดือน, โน้ต

### 8.7 วอลเปเปอร์
- Xe วาดวอลเปเปอร์เองใต้หน้า Home (ให้กระจกเบลอได้) **และตั้งเป็นวอลเปเปอร์ระบบให้ด้วย** (หน้าหลัก/ล็อก/ทั้งคู่)
- แหล่ง: Xe Collection (แถม 12 แบบ, ค่าเริ่มต้น = ดำนุ่ม), ที่สร้างใน Xe Studio, รูปจากแกลเลอรี (Photo Picker)
- เปลี่ยนวอลเปเปอร์จากตั้งค่า Samsung โดยตรง Xe จะไม่เห็น → บอกผู้ใช้ในหน้าวอลเปเปอร์

### 8.8 Xe Studio (ตัวสร้างแบบอิสระ)
เปิดจากโหมดแก้ไข / ตั้งค่า / ไอคอนแอป Xe Studio มี 3 เครื่องมือ ใช้ editor แบบเดียวกัน (canvas + เลเยอร์ + แถบเครื่องมือกระจกด้านล่าง):

**1. Wallpaper Creator**
- Mesh Gradient (เลือก 3–5 สี, สุ่ม, ความนุ่ม, grain)
- Abstract + Liquid Glass (รูปทรงลอย, เลนส์กระจก, สุ่ม)
- วาดด้วยนิ้ว (ปากกา, มาร์กเกอร์, แอร์บรัช, ยางลบ; ขนาด/สี/ความทึบ; undo/redo)
- แต่งรูปจากแกลเลอรี (ครอบ, เบลอ, ความสว่าง, ฟิล์มสี, ขาวดำ)
- ปลายทาง: ใช้เป็นหน้าหลัก/ล็อก/ทั้งคู่, บันทึกลงแกลเลอรี, บันทึกโปรเจกต์ไว้แก้ต่อ

**2. Icon Creator**
- พื้น: กระจกดำ / กระจกใส / สี / ไล่สี / รูป
- สัญลักษณ์: คลังไอคอนในแอป (~5,000 แบบ, Tabler Icons — MIT), ตัวอักษร, รูปจากแกลเลอรี, ไอคอนเดิมของแอป, หรือวาดเอง
- ทรง, ขนาด, สี, เงา, ขอบสะท้อนแสง
- ใช้กับแอปเดียว หรือสร้างเป็น "ชุดไอคอน" ใช้กับหลายแอป

**3. Widget Maker**
- ขนาด: 2×1, 2×2, 4×1, 4×2, 4×4; ทรง: สี่เหลี่ยมมน / แคปซูล / วงกลม
- พื้น: กระจก / สี / ไล่สี / รูป
- องค์ประกอบ: ข้อความ, เวลา (หลายฟอนต์), วันที่, วัน, % แบต, วงแหวนแบต, รูป, รูปทรง, ปุ่มเปิดแอป, กลุ่มไอคอนแอป
- ลากวาง ปรับขนาด สี ความหนา ของแต่ละองค์ประกอบ; บันทึกเป็นเทมเพลต
- Widget ที่สร้างเองใช้ได้ใน Xe Launcher เท่านั้น

## 9. หน้าตั้งค่า (Settings)

โครงสร้างตามแบบที่เจ้าของใช้ใน Smart Launcher แต่เป็นหน้าตา Xe (Large Title, แถวมีไอคอน, การ์ดกระจก):

- **การ์ดด้านบน:** "ไฮไลต์แอปที่มีการแจ้งเตือน" (ชวนเปิดสิทธิ์ Badge ถ้ายังไม่เปิด)
- **วอลเปเปอร์**
- **รูปลักษณ์:** ธีม สว่าง/มืด/อัตโนมัติ, สีเน้น, คุณภาพกระจก, ขนาดตัวอักษร, ภาษา (ระบบ/ไทย/English)
- **ไอคอน:** สไตล์, ทรง, ขนาด, ชื่อแอป, ความเข้มขาวดำ
- **แอนิเมชัน:** ความเร็ว (ปิด/เร็ว/ปกติ/นุ่ม), เอฟเฟกต์กดยุบ, parallax วอลเปเปอร์
- **ท่าทาง:** ปัดขึ้น/ลง, กดค้าง, ปัดสองนิ้ว ฯลฯ → เลือกการทำงาน
- **Xe Studio**
- **สำรอง/กู้คืน** (ไฟล์ .xebackup เก็บเลย์เอาต์, การตั้งค่า, หมวด, ไอคอน/วอลเปเปอร์/Widget ที่สร้าง)
- **หน้า (Pages):** หน้า Home, หน้าแอป, หน้าค้นหา — แต่ละหน้ามีการตั้งค่าของตัวเอง
- **เกี่ยวกับ:** เวอร์ชัน, ลิงก์เว็บไซต์, ตรวจหาอัปเดต (เช็ก GitHub Releases แล้วพาไปดาวน์โหลด)

## 10. แอนิเมชัน

ใช้สปริงฟิสิกส์ของ Compose ทั้งแอป (การตัดสินใจของ Claude ในรายละเอียด):

- **เลือกหมวด:** ฟองกระจกในแถบหมวด "ไหล" ไปยังหมวดใหม่แบบของเหลว (ยืดตัวระหว่างเคลื่อน แล้วหดคืนด้วยสปริง), ไอคอนในแถบเด้งเล็กน้อย, หัวข้อเลื่อน+จางสลับ, ไอคอนแอปเข้ามาทีละตัวแบบไล่ลำดับ (stagger: จาง + ขยาย + เลื่อนขึ้น)
- **ปัดเปลี่ยนหมวด:** ตารางเลื่อนตามนิ้ว ฟองกระจกเลื่อนตามสัดส่วนการปัด
- **เปิด App Drawer:** แผ่นเลื่อนตามนิ้ว ความเบลอค่อย ๆ เพิ่ม ไอคอนหน้า Home ย่อ/จางลง
- **เปิดแอป:** ไอคอนขยายออกเป็นหน้าแอป (ใช้ launch animation ของระบบจากตำแหน่งไอคอน)
- **โฟลเดอร์:** ขยายจากตำแหน่งโฟลเดอร์เป็นแผงกระจก
- **กดค้าง:** เมนูกระจกเด้งออกจากไอคอน, พื้นหลังเบลอ
- **โหมดแก้ไข:** ไอคอนสั่น, ลากแล้วไอคอนอื่นหลบแบบสปริง
- **ตั้งค่า:** เปลี่ยนหน้าแบบเลื่อน + จาง, สวิตช์กระจกแบบของเหลว
- **กด:** ปุ่มกระจกยุบ/ยืดเล็กน้อย + สั่นเบา (haptic)
- เคารพการตั้งค่า "ลบแอนิเมชัน" ของระบบ

## 12. โครงสร้างทางเทคนิค

- Kotlin, Jetpack Compose, Gradle Kotlin DSL + version catalog
- minSdk 29, targetSdk ล่าสุด; เบลอที่ API 31+, refraction ที่ API 33+, ต่ำกว่านั้นใช้ฟิล์มโปร่งแสง
- Activity เดียว ประกาศ `category.HOME`; Xe Studio และตั้งค่าเป็นหน้าภายในแอป (Navigation Compose)
- ข้อมูล: **Room** (เลย์เอาต์ Home, หมวด, การจับคู่แอป-หมวด, ไอคอนกำหนดเอง, Widget), **DataStore** (การตั้งค่า), ไฟล์ JSON + PNG ในพื้นที่แอป (โปรเจกต์ Studio)
- ไลบรารี: Compose BOM, Haze, Room, DataStore, Coil, kotlinx.serialization, Tabler Icons (SVG → vector)
- API ระบบ: LauncherApps, AppWidgetHost, WallpaperManager, NotificationListenerService, MediaStore, Photo Picker
- ไอคอนขาวดำ: แปลงภาพไอคอนเป็น grayscale ด้วย ColorMatrix (ปรับคอนทราสต์ได้), cache เป็นไฟล์
- แปลภาษา: `values/strings.xml` + `values-th/strings.xml`, per-app locale
